# Data sources

Raw files live in `data/raw/` (git-ignored; fetch with `uv run hd data download`, sizes are verified).
The cleaned corpus is rebuilt with `uv run hd data build` into `data/processed/corpus.parquet`.

| Genre | Side | Source | Files used | License (as stated on its Hugging Face card) |
|---|---|---|---|---|
| story | human | WritingPrompts, [`euclaise/writingprompts`](https://huggingface.co/datasets/euclaise/writingprompts), `validation` split | 1 parquet, 30.7 MB | MIT |
| story | AI | Generated by us on the same prompts with an open-weights model via Groq's free tier (`llama-3.3-70b-versatile`; the exact model id is stored per story) | `data/processed/ai_stories.jsonl` | Our own output (model license: Llama 3.3 community license) |
| essay | human + AI | HC3, [`Hello-SimpleAI/HC3`](https://huggingface.co/datasets/Hello-SimpleAI/HC3): `open_qa`, `finance`, `medicine`, `wiki_csai` | 4 jsonl, 17.7 MB | CC-BY-SA-4.0 |
| casual | human + AI | HC3 `reddit_eli5` | 1 jsonl, 55.4 MB | CC-BY-SA-4.0 |
| email | - | **Deferred.** No clean human-vs-AI paired dataset; Enron emails are private mail of real people. Listed as future work. | - | - |

## Caveats to carry into the findings report

- **WritingPrompts is Reddit user content.** The MIT label is the Hugging Face card's; the stories were
  written by Reddit users (Fan et al., 2018, *Hierarchical Neural Story Generation*). We use it for
  research and do not redistribute the raw text.
- **HC3 says** that source datasets with a stricter license keep it, otherwise CC-BY-SA applies. We did not
  audit each upstream source's license. HC3's AI side is **ChatGPT as of December 2022**, much older
  than the models people use now, so a detector trained on it is not evidence about current LLMs.
- **"Essay" really means explanatory Q&A answers**, not essays. Human medicine answers are doctor-forum
  replies with a recognizable greeting ("Hi, Thanks for the query"), a genre-specific shortcut.
- **Reddit ELI5 and open_qa human answers** were originally tokenized (`do n't`, `word ,`). See below.

## Cleaning, and why it matters

Before cleaning, the human side of HC3 and WritingPrompts carried artifacts that the AI side lacked:

| Artifact | Human text | ChatGPT text |
|---|---|---|
| Space before punctuation (`word ,`), reddit_eli5 | 98.7% of answers | 0.1% |
| Split contractions (`do n't`), reddit_eli5 | 66.2% | 0% |
| Padded newlines (`" \n "`), wiki_csai | 3.9% | 86.9% |

A classifier would reach high accuracy by reading the tokenizer's fingerprints, not the writing. So
`hd.data.clean.normalize_text` is applied identically to every text (detokenizing, straightening curly
quotes, trimming newline padding), and texts that still show tokenization, URLs/URL placeholders, CJK
characters, or (for generated stories) markdown are dropped. After cleaning, every artifact rate above is 0 on
both sides. The genuine differences remain (see below).

## Known remaining confounds (handled in later milestones)

- **Length:** ChatGPT answers are ~2x longer than human ones (median ~175 vs ~84 words). Raw length will be
  excluded from the features and reported with a length-matched evaluation.
- **Line breaks:** AI casual answers average ~2 line breaks versus 0 for human; paragraph structure is
  a legitimate style signal but also partly a Reddit-format artifact. Reported as a feature, ablated.
- **Stories:** human stories are cleaned, but the LLM-written stories are not generated yet (needs a Groq key). Their AI side will be Llama-3.3-70B text, a different generator from HC3's 2022 ChatGPT, so the story and essay/casual results are not directly comparable.
  Target length mirrors each human story, so length should not leak there.

## Splits

Train/val/test = 70/15/15, assigned **per prompt** by a stable hash of `(seed, prompt_id)`, never per text.
A human/AI pair therefore always lands on the same side, and adding data later never moves an existing
prompt. The test split is guarded in code (`hd.data.splits.load_split`): it raises unless explicitly
unlocked, and every unlock is logged. It is used once, for the final evaluation.

Current paired counts (texts, human + AI): see `results/corpus_summary.csv`.
